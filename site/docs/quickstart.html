Quickstart

From a fresh install to your first mined alphas in about fifteen minutes — most of it unattended.

1. Install

  • Linux: download AlphaNode-x86_64.AppImage, make it executable (chmod +x), run. A .deb package is also available.
  • Windows: run AlphaNode-Setup.exe, or unzip the portable build anywhere and run AlphaNode.exe.

The app ships with a starter data snapshot (50 pairs, daily bars), so the search works out of the box before you download anything.

2. Pick a timeframe and download data

In SEARCH SETTINGS, choose the bar size — 1d, 4h, 1h or 15m. Picking one auto-fills the recommended history window and pair count for that bar size (see Timeframes). Then press Download data: the node fetches OHLCV + funding history for the top Binance USDT-perp pairs into a per-timeframe snapshot. Daily data takes a couple of minutes; 15m takes longer — the app shows progress.

3. Start the node

Press ▶ Start. The node runs continuous search rounds: each round evolves a population of formulas for a configured number of generations, then merges the champions into your alpha library. You'll see:

  • the live status line (round, generation, evaluations/sec);
  • the progress chart (best fitness per generation);
  • the leaderboard — the library's top alphas with TRAIN / VAL / TEST metrics.
TEST numbers are shown for information only — the search never selects by them. A good habit: sort by TEST once a day, not every five minutes.

4. Build a portfolio

In the PORTFOLIO panel set top N and press Build portfolio. The builder picks the top-N diverse alphas from the library and combines them through the engine's portfolio layer (second vol-targeting pass + position inertia). You get combined TEST metrics vs buy-&-hold, an equity chart, and per-bar target weights.

5. Act on it

  • CSV — download per-bar target weights of the combined portfolio.
  • PDF — a full analytics report (equity, drawdown, exposure, per-alpha stats).
  • Signal API — serve the current target positions as a local JSON endpoint (daily).
  • Paper bundle — export a self-contained paper-trading kit (daily).

Running headless (CLI)

Everything the GUI does, scripted — for servers, ssh or Docker:

# continuous search, 50% CPU, population 200, 25 generations per round
alphanode run --cpu 50 --pop 200 --gens 25

# inspect the library
alphanode top --sort test --min-test 1
alphanode status
Everything AlphaNode shows is a hypothetical backtest, not investment advice. Verify any alpha with a forward/paper run on new data before it means anything.
